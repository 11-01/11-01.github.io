🧩 交互描述五要素

一条合格的交互提示词 = 五个要素。缺一个，AI 就要靠猜。

01
触发器
用户做了什么动作
→
02
目标
哪个元素发生变化
→
03
动作
发生了什么（时长/缓动）
→
04
反馈
用户感知到什么
→
05
边界
异常情况怎么办
示例：用户点击【选包】按钮（触发）→ 唤起半屏弹窗（目标）→ 从底部滑入 300ms ease-out，展示 6 个包位卡片（动作）→ 点选卡片高亮描边 + 轻震动（反馈）→ 库存为 0 置灰禁用；点遮罩关闭；连点只触发一次（边界）
